## 💻 Comandos Básicos de Git

### Ver el estado del repositorio
```bash
git status
```
Muestra qué archivos han sido modificados y cuáles están listos para el commit.

### Ver el historial de commits
```bash
git log --oneline
```
Muestra todos los commits realizados en el proyecto.

### Agregar cambios
```bash
git add .
```
Prepara todos los cambios para ser confirmados.

### Guardar cambios (Commit)
```bash
git commit -m "Descripción de los cambios"
```
Guarda los cambios con un mensaje descriptivo.

### Subir cambios al repositorio remoto
```bash
git push
```
Envía tus cambios al servidor remoto (GitHub, GitLab, etc.).

### Descargar cambios del repositorio remoto
```bash
git pull
```
Descarga los cambios más recientes del repositorio remoto.

## ❓ Preguntas Frecuentes

**P: ¿Qué hago si hay conflictos al hacer pull?**
R: Edita manualmente los archivos conflictivos, luego haz `git add` y `git commit`.

**P: ¿Puedo deshacer el último commit?**
R: Sí, usa: `git reset --soft HEAD~1`

**P: ¿Cómo veo los cambios específicos?**
R: Usa: `git diff` para cambios no guardados o `git log -p` para cambios en commits.
